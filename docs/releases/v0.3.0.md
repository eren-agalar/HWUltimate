## HWUltimate 0.3.0

First public release (previously "Nova Hardware").

**Download:** `HWUltimate-v0.3.0-win-x64.zip` below · requires Windows 10/11 x64 and the [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0).
For motherboard, fan, voltage and per-core CPU sensors also install [PawnIO](https://pawnio.eu/).

### English
- **Sensors:** classic Device → Group → Sensor tree with Sensor · Value · Min · Max; every core temperature under *Temperatures*; Super I/O / EC sensors under the motherboard.
- **Complete detection:** *Rescan hardware* without restarting; automatic re-detection after start-up when detection looks incomplete; banner when the PawnIO driver is missing.
- **Clean by default:** unused sensors (never reported, empty fan headers, unconnected inputs, virtual / disconnected network adapters) are hidden; *Show all sensors* brings them back.
- **Hide permanently:** sensors, whole devices or groups stay hidden after restarts, even when drives are renumbered; *Hidden* list to show them again.
- **Hardware page:** device tree, Feature · Description · Source table and a one-page *System summary*.
- **Silicon quality:** factory per-core ranking (Intel favored cores / AMD preferred cores) read from the firmware through Windows.
- **Memory** named from SMBIOS (e.g. "32 GB DDR5-6000 (2 × 16 GB)").
- **In-app updates:** HWUltimate checks GitHub Releases, notifies you and installs new versions after verifying their SHA-256.
- New animated vector logo; dropdowns fixed; Mini Overlay and Alerts removed.
- Settings, hidden sensors and reports are copied automatically from the old *Nova Hardware* folder.

### Türkçe
- **Sensörler:** Cihaz → Grup → Sensör ağacı, Sensör · Değer · Min · Max sütunları; tüm çekirdek sıcaklıkları *Sıcaklıklar* altında; Super I/O / EC sensörleri anakartın altında.
- **Eksiksiz algılama:** yeniden başlatmadan *Donanımı yeniden tara*; algılama eksik görünürse açılıştan sonra otomatik tekrar; PawnIO sürücüsü eksikse uyarı.
- **Varsayılan olarak sade:** kullanılmayan sensörler (hiç değer bildirmeyen, boş fan girişleri, bağlı olmayan girişler, sanal / bağlı olmayan ağ bağdaştırıcıları) gizlenir; *Tüm sensörleri göster* ile geri gelir.
- **Kalıcı gizleme:** sensörler, cihazlar veya gruplar yeniden başlatmadan sonra da gizli kalır, diskler yeniden numaralansa bile; *Gizli* listesinden geri açılır.
- **Donanım sayfası:** cihaz ağacı, Özellik · Açıklama · Kaynak tablosu ve tek sayfalık *Sistem özeti*.
- **Silikon kalitesi:** Windows üzerinden ürün yazılımından okunan fabrika çekirdek sıralaması (Intel favored cores / AMD preferred cores).
- **Bellek** adı SMBIOS'tan (ör. "32 GB DDR5-6000 (2 × 16 GB)").
- **Uygulama içi güncelleme:** HWUltimate GitHub Releases'ı denetler, bildirim gösterir ve yeni sürümleri SHA-256 doğrulamasından sonra kurar.
- Yeni hareketli vektör logo; açılır kutular düzeltildi; Mini Overlay ve Uyarılar kaldırıldı.
- Ayarlar, gizlenen sensörler ve raporlar eski *Nova Hardware* klasöründen otomatik kopyalanır.

**SHA-256:** see `HWUltimate-v0.3.0-win-x64.zip.sha256` / `HWUltimate-v0.3.0-win-x64.zip.sha256` dosyasına bakın.
